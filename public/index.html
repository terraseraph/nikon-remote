Triggers

Voice, clap and webcam gestures need the microphone/camera, which phones only allow over https. Use them on the laptop — gestures watching the Nikon's live view still work here.

What can I say?
  • “shoot”, “capture”, “cheese”, “take a picture”
  • “timer five” / “in ten seconds”
  • “burst three” / “five shots”
  • “focus”
  • “brighter” / “darker” (exposure comp)
  • “ISO up” / “ISO down” / “ISO 800”
  • “start recording” / “action” · “stop recording” / “cut”
  • “zoom in” / “zoom out”
  • “live view on/off”, “start/stop time-lapse”
  • “stop” / “cancel”
